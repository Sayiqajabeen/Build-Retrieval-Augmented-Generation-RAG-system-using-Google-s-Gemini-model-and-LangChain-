# RAG Project with Gemini and LangChain

This project implements a Retrieval-Augmented Generation (RAG) system using Google's Gemini model and LangChain framework. The system can answer questions based on retrieved context from a given document.

## Features

- Web scraping with BeautifulSoup
- Document splitting and chunking
- Vector embeddings with Google's Gemini
- Vector storage with ChromaDB
- Question answering with retrieval-augmented generation
- Integration with LangChain components


## Environment Variables
You'll need to set up the following environment variables:

export GOOGLE_API_KEY="your_google_api_key"
export LANGCHAIN_TRACING_V2="true"
export LANGCHAIN_ENDPOINT="https://api.smith.langchain.com"
export LANGCHAIN_API_KEY="your_langsmith_api_key"
export LANGCHAIN_PROJECT="RAG"
